# AI & ML Practicals

Repository for Artificial Intelligence (AI) and Machine Learning (ML) practical implementations.

## Branch Structure

```
main
└── dev
    ├── feature/ML-pr1  through  feature/ML-pr12
    └── feature/AI-pr1  through  feature/AI-pr13
```

## Structure

| Category | Practicals |
|----------|-----------|
| Machine Learning (`ML/`) | pr1 – pr12 (12 practicals) |
| Artificial Intelligence (`AI/`) | pr1 – pr13 (13 practicals) |

## Workflow

- Each practical has a dedicated `feature/` branch
- Feature branches are merged into `dev` via pull requests
- `dev` is the integration branch
- `main` is the stable default branch
